<h3>Arduino Uno Revision 3 Specifications:</h3>
<ul>
  <li><b>Dimensions:</b> 68.6 mm L x 53.4 mm W</li>
  <li><b>Weight:</b> 25 g</li>
  <li>
    <b>Processors:</b>
    <ul>
      <li><b>Main Processor:</b> ATmega328P 16 MHz</li>
      <li><b>USB-Serial Processor:</b> ATmega16U2 16 MHz</li>
    </ul>
  </li>
  <li>
    <b>Memory:</b>
    <ul>
      <li>
        <b>ATmega328P:</b>
        <ul>
          <li><b>SRAM:</b> 2 kB</li>
          <li><b>Flash:</b> 32 kB</li>
          <li><b>EEPROM:</b> 1 kB</li>
        </ul>
      </li>
      <li>
        <b>ATmega16U2:</b>
        <ul>
          <li><b>SRAM:</b> 512 bytes</li>
          <li><b>Flash:</b> 16 kB</li>
          <li><b>EEPROM:</b> 512 bytes</li>
        </ul>
      </li>
    </ul>
  </li>
  <li><b>USB Connector:</b> USB Type-B</li>
  <li>
    <b>Supported Communication Protocols:</b>
    <ul>
      <li>Serial over USB Type-B</li>
      <li>Serial over Digital Pins 0 (RX) and 1 (TX)</li>
      <li>I2C</li>
      <li>SPI</li>
      <li>UART</li>
      <li>USART</li>
    </ul>
  </li>
  <li>
    <b>Input/Output Pins:</b>
    <ul>
      <li><b>14</b> Digital I/O pins, <b>6</b> of them provide PWM output (pins 3, 5, 6, 9, 10 and 11)</li>
      <li><b>6</b> Analog Input Pins</li>
    </ul>
  </li>
  <li>
    <b>Power:</b>
    <ul>
      <li>
        <b>Input Power Voltage Over Different Connectors:</b>
        <ul>
          <li><b>7-12 V</b> (nominal) over Barrel Plug</li>
          <li><b>5 V</b> over USB Type-B</li>
        </ul>
      </li>
      <li><b>I/O Voltage: 5 V</b></li>
      <li><b>o	DC Current per I/O Pin: 20 mA</b></li>
    </ul>
  </li>
</ul>
