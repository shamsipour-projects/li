<h3>Arduino Mega Revision 3 Specifications:</h3>
<ul>
  <li><b>Dimensions:</b> 101.5 mm L x 53.3 mm W</li>
  <li><b>Weight:</b> 37 g</li>
  <li>
    <b>Processors:</b>
    <ul>
      <li><b>Main Processor:</b> ATmega2560 16 MHz</li>
      <li><b>USB-Serial Processor:</b> ATmega16U2 16 MHz</li>
    </ul>
  </li>
  <li>
    <b>Memory:</b>
    <ul>
      <li>
        <b>ATmega2560:</b>
        <ul>
          <li><b>SRAM:</b> 8 kB</li>
          <li><b>Flash:</b> 256 kB (of which 8 kB is used for the bootloader)</li>
          <li><b>EEPROM:</b> 4 kB</li>
        </ul>
      </li>
      <li>
        <b>ATmega16U2:</b>
        <ul>
          <li><b>SRAM:</b> 512 bytes</li>
          <li><b>Flash:</b> 16 kB</li>
          <li><b>EEPROM:</b> 512 bytes</li>
        </ul>
      </li>
    </ul>
  </li>
  <li><b>USB Connector:</b> USB Type-B</li>
  <li>
    <b>Supported Communication Protocols:</b>
    <ul>
      <li>Serial over USB Type-B</li>
      <li>Serial over Digital Pins 0 (RX0), 1 (TX0), 19 (RX1), 18 (TX1), 17 (RX2), 16 (TX2), 15 (RX3), 14 (TX3)</li>
      <li>I2C</li>
      <li>SPI</li>
      <li>UART</li>
      <li>USART</li>
    </ul>
  </li>
  <li>
    <b>Input/Output Pins:</b>
    <ul>
      <li><b>54</b> Digital I/O pins, <b>15</b> of them provide PWM output (pins 2-13 and 44-46)</li>
      <li><b>16</b> Analog Input Pins</li>
    </ul>
  </li>
  <li>
    <b>Power:</b>
    <ul>
      <li>
        <b>Input Power Voltage Over Different Connectors:</b>
        <ul>
          <li><b>7-12 V</b> (nominal) over Barrel Plug</li>
          <li><b>5 V</b> over USB Type-B</li>
        </ul>
      </li>
      <li><b>I/O Voltage: 5 V</b></li>
      <li><b>o	DC Current per I/O Pin: 20 mA</b></li>
    </ul>
  </li>
</ul>
